# GT4Recomp 1.2.5

**More ways to adjust how your controller responds.**

## New

- Choose from seven controller response curves, including four new options.
- Preview your response settings before playing.

## Good to know

- Keeps RetroAchievements and the existing settings and save layout from 1.2.4.
- Uses the English interface and supports GT4 USA v2.00.
- Racing-wheel support is not included in this update.
