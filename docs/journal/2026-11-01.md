## TASK-146: Memory card save creation and first-boot halt diagnosis (Issue #160)

- Completed technical investigation of GitHub Issue #160 ("Problem with save game - Memory card", report from *rinegan33* with 1080p screenshot of the initial GT4 memory card creation dialog: *"No Gran Turismo 4 data found on MEMORY CARD slot 1. Do you want to create game data? Yes / No"* and statement *"I can't start the game I need help with this problem"*).
- Documented analysis in `docs/TASK-146-MEMORY-CARD-SAVE-ISSUE-STUDY.md`.
- Analyzed GT4's initial memory card boot flow:
  - On startup, the EE engine queries `mc0:` for `BASCUS-97328GAMEDATA`.
  - When absent, GT4 prompts with a modal creation dialog.
  - As established empirically in `docs/reverse-engineering/slice110-external-menu-pilot.md` (`name-control2`, `name-control3`, `name-control4`), the creation wizard requires multiple interactive confirmations:
    1. Initial creation prompt (responds exclusively to `Cross`, ignores `Start`/Enter).
    2. Free space verification (1,488 KB required, confirm with `Cross`).
    3. Format prompt (crucially, `Cancel` is selected by default; requires D-Pad Right + `Cross` to confirm).
    4. Multiple informative dialogs (Autosave, memory card protection).
- Identified three root causes:
  1. *Input friction / keyboard mapping mismatch:* PC players naturally press `Enter` (mapped to `Start`), `Space` (unmapped), or `A` (mapped to `Square`). Because none of these keys register on GT4's creation modal, players assume the game has frozen.
  2. *Blank card construction:* When no active save exists, `gt4saves` constructs an empty formatted card with `Card::build(&[])`, forcing 100% of first-time players through the 5-screen interactive wizard.
  3. *Filesystem locking / permissions:* `CreateFileA` on `runtime\card.ps2.lock` without sharing flags fails with error 32 if an orphaned instance or antivirus holds the lock.
- Established three-phase remediation architecture:
  - Phase 1: Clear onboarding reminder banner in launcher / game window explaining keyboard defaults (`Z` for Cross/Confirm, `X` for Circle, Arrows for D-Pad, Enter for Start).
  - Phase 2: Save auto-initialization in `gt4saves`, pre-seeding standard `BASCUS-97328GAMEDATA` so fresh installs skip the dialog entirely and boot directly into the Main Menu.
  - Phase 3: Stale lock recovery and clear user-facing diagnostics.
- Ran test suite: `gt4l-core` unit tests (105 passed), launch contract tests (16 passed), and Python shape/cost tests passed without regressions.
