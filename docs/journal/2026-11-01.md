## TASK-103: Graphics API choice for GSdx (Vulkan, Direct3D 12, Direct3D 11)

- Exposed Graphics API selection row for GSdx in Launcher Settings.
- Hardware backends supported:
  - Vulkan (`Renderer = 14`, default/recommended)
  - Direct3D 12 (`Renderer = 15`, recommended)
  - Direct3D 11 (`Renderer = 3`, older PCs)
  - Software rendering and OpenGL are strictly excluded.
- UI separation: Launcher engine setting retains `id = "renderer"` (`"pcsx2"` / `"coregs20"`), while the GSdx backend option uses `id = "graphics_api"`.
- INI mapping: `gs_table::canonical_id` aliases `"graphics_api"` to `"renderer"` so that `render_ini` generates `[EmuCore/GS] Renderer` with the correct backend index.
- Configuration persistence: stored under `[gs]` as `graphics_api = "vulkan" | "d3d12" | "d3d11"`. Legacy configs with `[gs] renderer = "..."` load cleanly and migrate to `graphics_api` on next save.
