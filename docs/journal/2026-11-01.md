- Authored comprehensive architectural study: [`docs/TASK-145-XBOX-BUTTON-PROMPTS-STUDY.md`](../TASK-145-XBOX-BUTTON-PROMPTS-STUDY.md) addressing [Issue #161](https://github.com/moesuito/gt4-staticrecomp/issues/161).

- Analyzed GT4's UI rendering architecture:
  - Button icons are static textures compiled into `.gpb` files within `GT4.VOL` (navigation bars, license test instructions, and in-race HUD telemetry).
  - Uploaded to the Graphic Synthesizer as paletted or 32-bit textures with invariant, deterministic texture hashes.
- Established clean-room implementation architecture:
  - Leverages the existing GSdx texture replacement pipeline (`LoadTextureReplacements = true`, `[Folders] Textures`).
  - Bundles clean, permissively licensed (CC0 Public Domain) button prompt replacement graphics (Green A, Red B, Blue X, Yellow Y, LB, RB, LT, RT).
  - Adds `button_prompts = "playstation" | "xbox" | "switch"` setting to `gt4l-core::settings` and a dedicated dropdown under Launcher Settings > Controls.
  - Zero modifications to the game executable or AOT translation; 100% clean-room compliant with Decision 0070.
  - Reversible and seamlessly compatible with both Windows bare metal and SteamOS / Proton on Steam Deck.
