## TASK-215: H-Shifter, Direct Gear Application and Clutch State Machine

On branch `task/215-hshifter-mod`:
- Implemented the pure host logic module `native/hshifter_mod.{hpp,cpp}` for the opt-in H-shifter and clutch gameplay mod
  under owner decision 0073 (`docs/decisions/0073-mod-support-in-bundle.md`) and specification
  `docs/H-SHIFTER-CLUTCH-MOD-STUDY.md`.
- Enforces the project invariants:
  - Opt-in switch `GT4_MOD_HSHIFTER` / `mod_hshifter`, off by default.
  - Safe direct gear application without step sequencing.
  - Reverse lock when speed exceeds 0.2778 m/s (~1 km/h).
  - Gear clamping to the car's forward gear count (`Engine + 0x236`).
  - Clutch requirement for gear transitions when `auto_clutch_assist` is disabled.
  - Analog clutch engagement curve from pedal bite point to full release.
  - HUD character selection ('R' vs 'N' on gear 0).
  - Automatic refusal and bypass on automatic transmission vehicles.
- Implemented `native/hshifter_guest.{hpp,cpp}`:
  - Discovers player `Automobile` object via the live `RaceDisplay` chain (`RaceDisplay -> RaceOrganization -> Cars -> CarRecord -> Automobile`).
  - Reads live vehicle telemetry (speed, RPM, max RPM, gear count, transmission type).
  - Injects target gear (`+0x624`), clutch state (`+0x626`), engagement float (`+0x618`), suppresses guest sequential shift requests (`+0x567`, `+0x566`, `+0x62A`), and updates host parameter block (`0x7F10..0x7F16`).
- Integrated into wheel subsystem and window VBlank loop:
  - `native/wheel.{hpp,cpp}`: added `ShifterConfig` supporting `[shifter]` table (`enabled`, `reverse`, `gear_1..8`), analog clutch pedal channel evaluation (`clutch_pedal()`), and digital gate decoding (`shifter_gate()`).
  - `native/window.cpp`: integrated mod update in `on_vblank()`, checking `GT4_MOD_HSHIFTER=1`, polling wheel clutch/gate inputs with keyboard fallback bindings ('C' for clutch, '1'..'6' and 'R' for gates), and injecting results into guest RAM.
  - `native/display_aspect.cpp`: hooked `on_race_display_render` to register active `RaceDisplay` pointer with `note_race_display()`.
