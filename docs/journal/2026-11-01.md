# 2026-11-01 — TASK-078: In-game graphics settings & permanent 480p progressive hold

## Summary

Implemented TASK-078 to provide host graphics settings synchronization with the game's Options menu and enforce a permanent progressive 480p hold across all game modes:

1. **Permanent 480p progressive hold (`native/race_display.{hpp,cpp}`)**:
   - `should_force_480p_index` now returns `true` for any value other than `race_display_index_480p` (1), forcing both normal (0) and 1080i (2) to 1.
   - Ensures all races run progressive 480p even when loading legacy memory card saves that previously set 1080i.

2. **Decoupling from memory card (`native/ingame_settings.{hpp,cpp}`)**:
   - `handle_guest_option_write` intercepts option writes to `option + 0x16B0`, updates the host `ResolutionPreset`, and ensures guest RAM holds `1` (480p).
   - Prevents host internal resolution values from corrupting PS2 memory card save portability.

3. **In-game graphics settings manager**:
   - Manages 6 resolution presets: 480p (1x), 720p (2x), 1080p (3x), 1440p (4x), 4K (6x), 8K (12x).
   - Manages fullscreen toggle and anti-aliasing (FXAA).
   - Synchronized with `native/window.cpp` on `set_fullscreen` (Alt+Enter / F11) and `open_window`.

4. **Atomic feedback persistence**:
   - Atomic file write to `game-changes.toml` (`GT4_SETTINGS_FEEDBACK`) via temporary file and atomic replace.

5. **Launcher synchronization**:
   - `launcher/crates/gt4l-core/src/paths.rs`: added `UserDirs::game_changes_file()`.
   - `launcher/crates/gt4l-core/src/config.rs`: added `preset_to_resolution` and `merge_game_changes`.
   - `launcher/crates/gt4l-tauri/src/commands.rs`: passes `GT4_SETTINGS_FEEDBACK` to game environment and merges changes on game exit.
   - `launcher/crates/gt4l-tauri/src/state.rs`: merges changes on startup.
